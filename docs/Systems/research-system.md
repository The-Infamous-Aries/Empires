# Research System (Technical Reference)

**File:** `systems/research-system.js`
**Class:** `ResearchSystem`
**Global:** `window.ResearchSystem`

---

## Overview

The Research System is a unified, goal-based technological advancement framework. Research is funded per-turn from Laboratory income diversion (a percentage of net turn revenue). Each research project has a cost (research points goal). Labs divert income each turn until the goal is reached, then research auto-completes and the player can pick another project.

Research is **NOT time-based**. There are no hours, days, or timers. Progress is measured in research points, funded by Laboratory income diversion from tax revenue.

---

## Architecture

```
Research Data Files (assets/data/research/*.js)
        ↓
ResearchSystem (systems/research-system.js)
        ↓
Technology Entity (entities/Technology.js)
        ↓
Nation (entities/Nation.js)
```

## Category Structure

Three research branches exist:

| Category | Description | Data File |
|----------|-------------|-----------|
| `economy` | Financial systems, trade, economic development | `economy-research.js` |
| `healthcare` | Medical knowledge, public health, disease management | `healthcare-research.js` |
| `war` | Military technology, tactics, warfare evolution | `war-research.js` |

**Note:** `production-research.js` was removed — resources no longer exist in the game.

---

## Constructor

```javascript
new ResearchSystem()
```

Initializes:
- `researchDatabase` (Map) — all loaded research projects keyed by ID
- `activeResearch` (Map) — nationId → array of active research projects
- `completedResearch` (Map) — nationId → Set of completed research IDs
- `categories` — `['economy', 'healthcare', 'war']`
- `maxTiers` — `12`
- `maxSimultaneousResearch` — `1` (can be increased by Great Library wonder)
- `labBasePercentage` — `0.025` (2.5% of net income per lab)
- `labMaxStack` — `4` (max 4 labs = 10%)
- `labPollutionPerLab` — `5` (+5 pollution per lab)
- `labDiseasePerLab` — `5` (+5 disease per lab)

## Methods

### Data Management

#### `initialize()` → `Promise<void>`
Sets up event handlers. Logs "Research System initialized".

#### `setResearchDatabase(researchData)`
Loads research data from an object into `researchDatabase`. Emits `research:database_loaded` event via EventBus.

#### `getResearchData()` → `object`
Returns research data from the first available source:
1. `this.researchData`
2. `dataIntegration.getAllResearch()`
3. `ResearchDatabase.research`
4. `{}`

#### `getAvailableCategories()` → `string[]`
Returns a copy of the `categories` array: `['economy', 'healthcare', 'war']`.

#### `getTechLevelInfo()` → `object`
Returns tech level descriptions (1–12). Falls back to built-in descriptions if `this.researchData.techLevels` is not available.

#### `getResearchStatistics()` → `object`
Returns:
- `total` — count of all research projects
- `byCategory` — count per category
- `byTier` — count per tier (1–12)

## Laboratory / Research Income

### `getLabResearchIncome(nation)` → `number`
Calculates research points generated by Laboratories this turn.

**Formula:**
```
effectiveCount = min(labCount, 4)
percentage = 2.5% (base)

If Advanced Research Institute built (≥1): percentage = 3.5%
If Grand Research Academy built (≥1 AND Advanced Research built): percentage += 1.5%

researchIncome = floor(netIncome × percentage × effectiveCount)
```

| Condition | Rate per Lab | 4 Labs Total |
|-----------|-------------|--------------|
| Base | 2.5% | 10% |
| + Advanced Research Institute | 3.5% | 14% |
| + Grand Research Academy | 5.0% | 20% |

**Note:** Net income = `nation.taxRevenue`. No laboratories = no research funding possible.

### `getLabPenalties(nation)` → `object`
Returns pollution and disease from laboratories.

| Condition | Pollution per Lab | Disease per Lab |
|-----------|------------------|-----------------|
| Base | +5 | +5 |
| + Advanced Research Institute | +6 | +6 |
| + Grand Research Academy | +8 | +8 |
| + Environmental Research Complex | ÷2 | ÷2 |

Returns `{ pollution, disease, perLab: { pollution, disease } }`.

### `applyLabEffects(nation)`
Updates `nation.improvementEffects` with lab pollution, disease, count, and income. Called when labs are built/demolished or when projects/wonders affecting labs change.

## Research Management

### `getNation(nationId)` → `object`
Looks up a nation via `window.DataManager.currentPlayer.nations`, falling back to `window.Nation`.

### `canStartResearch(nationId, researchId)` → `{success, reason}`
Checks if a nation can start a research project:

| Check | Condition | Failure Reason |
|-------|-----------|----------------|
| Nation exists | `nation` found | `"Nation not found"` |
| Research exists | `research` in database | `"Research not found"` |
| Active research slot | `activeCount < maxResearch` | `"Maximum research projects active"` |
| Tech level | `nation.tech ≥ research.requirements.tech_level` | `"Tech level {n} required"` |
| Prerequisites | All prerequisite IDs in `completedResearch` | `"Prerequisite '{id}' not completed"` |
| Not already researched | `researchId` not in `completedResearch` | `"Already researched"` |

### `startResearch(nationId, researchId)` → `{success, project}`
Starts researching via `canStartResearch()`. Creates an active research project with `progress: 0`, `goal: research.cost`, `isActive: true`, `startedAt: Date.now()`.

### `cancelResearch(nationId, researchId)` → `boolean`
Removes an active research project. Returns `false` if not found.

### `getActiveResearch(nationId)` → `object\|undefined`
Returns the currently active research project for a nation (or `undefined`).

### `getActiveResearchCount(nationId)` → `number`
Returns the count of active (`isActive === true`) research projects.

### `getMaxSimultaneousResearch(nationId)` → `number`
Returns `1` by default, `+1` if Great Library wonder is built.

### `getCompletedResearch(nationId)` → `object[]`
Returns all completed research for a nation, sorted by tier.

### `getResearchProgress(nationId, researchId)` → `number`
Returns raw research points invested (0 to `cost`). Returns `0` if no active project.

### `getResearchTimeRemaining(nationId, researchId)` → `number`
Estimates turns remaining: `Math.ceil(remaining / labIncome)`. Returns `Infinity` if no lab income.

### `processResearchTurn(nation)` → `void`
Called each turn/day from `Nation.handleDayPassed()`:
1. Returns early if no laboratories (`labCount === 0`)
2. Generates research income from labs → `nation.researchPoints`
3. Applies lab pollution/disease via `applyLabEffects()`
4. Funds active research from `nation.researchPoints`
5. Auto-completes when `progress ≥ goal`

### `completeResearch(nation, project)` → `void`
Marks research complete:
1. Sets `isActive = false`, `completedAt = Date.now()`
2. Adds `researchId` to `completedResearch`
3. Applies effects via `applyResearchEffects()`
4. Rebuilds modifiers via `rebuildModifiers()`
5. Emits `research_completed` event via EventBus

### `applyResearchEffects(nationId, research)` → `void`
Accumulates research effect keys/values into `nation.researchEffects`.

### `rebuildModifiers(nationId)` → `void`
Converts `nation.researchEffects` into consumable `nation.researchModifiers` using `effectMap`. All modifier stats start at 0 and accumulate matching effects.

## Effect → Modifier Mapping

All effect keys from research data files map to modifier stats:

| Effect Key | Modifier Stat |
|------------|---------------|
| `attack_power`, `weapon_effectiveness`, `weapon_quality`, ... | `attack` |

| `aim`, `accuracy`, `ranged_attack`, `bow_power`, ... | `aim` |
| `luck` | `luck` |
| `critical_chance` | `critChance` |
| `critical_damage` | `critDamage` |
| `block`, `parry`, `block_chance`, `parry_chance` | `block`, `parry` |
| `soldier_cost_reduction`, `tank_cost_reduction`, ... | `soldierCostReduction`, ... |
| `soldier_upkeep_reduction`, ... | `soldierUpkeepReduction`, ... |

| `missile_damage_boost`, `nuke_damage_boost`, ... | `missileDamageBoost`, `nukeDamageBoost` |
| `disease_spawn_rate_reduction` | `diseaseSpawnReduction` |
| `disease_level_reduction` | `diseaseLevelReduction` |
| `pollution_reduction` | `pollutionReduction` |
| `cure_cost_reduction` | `cureCostReduction` |
| `population_growth_bonus` | `populationGrowthBonus` |
| `population_boost` | `populationBoost` |
| `energy_skill_bonus` | `energySkillBonus` |
| `intuition_skill_bonus` | `intuitionSkillBonus` |
| `taxable_income_boost` | `taxableIncomeBoost` |
| `crime_reduction` | `crimeReduction` |
| `happiness_bonus` | `happinessBonus` |

| `infra_upkeep_reduction` | `infraUpkeepReduction` |
| `infra_cost_reduction` | `infraCostReduction` |
| `land_cost_reduction` | `landCostReduction` |

### `getResearchModifier(nationId, stat)` → `number`
Returns a specific modifier stat value for a nation (or `0` if not set).

## API Methods for UI

### `getAvailableResearch(nationId, category?)` → `object[]`
Returns research available to start for a nation:
- Filters by `category` if provided
- Excludes already-completed research
- Excludes research above `nation.tech` level
- Includes `canStart`, `reason`, `progress` (0) fields
- Sorted by tier

### `getResearchTree(category)` → `object`
Returns research grouped by tier for a category. Each entry includes `id`, research data, `prerequisites`, and `unlocks`.

### `getCategoryInfo()` → `object`
Returns category metadata:
```javascript
{
    economy: { name: 'Economy', description: 'Financial systems and trade', icon: '💰' },
    healthcare: { name: 'Healthcare', description: 'Medical knowledge and public health', icon: '🏥' },
    war: { name: 'Military', description: 'Military technology and tactics', icon: '⚔️' }
}
```

## Wonders

### `handleWonderEffects(data)` → `void`
Handles `wonder_completed` events. Currently handles `great_library` (log message only; the +1 research slot is handled in `getMaxSimultaneousResearch`).

## Notifications

### `notifyResearchStarted(project)`, `notifyResearchCompleted(project)`, `notifyResearchCancelled(project)`
Emit events via EventBus if available:
- `research_started`
- `research_completed_notification`
- `research_cancelled`

## EventBus Events

| Event | Data | Source |
|-------|------|--------|
| `research:database_loaded` | `{count, categories}` | `setResearchDatabase()` |
| `research_started` | `{nationId, research, message}` | `notifyResearchStarted()` |
| `research_completed_notification` | `{nationId, research, message}` | `notifyResearchCompleted()` |
| `research_cancelled` | `{nationId, researchId, message}` | `notifyResearchCancelled()` |
| `research_completed` | `{nationId, researchId, research}` | `completeResearch()` |

## Integration Points

| System | Integration |
|--------|-------------|
| `Nation.handleDayPassed()` | Calls `processResearchTurn()` each day |
| `Nation.startResearch()` / `cancelResearch()` | Delegates to `ResearchSystem` |
| `Nation.getAvailableResearch()` | Delegates to `ResearchSystem.getAvailableResearch()` |
| `disease-system.js` | Reads `researchModifiers.diseaseSpawnReduction`, `cureCostReduction` |
| `world.js` | Applies `infraUpkeepReduction` to building upkeep |
| `Player.js` | Applies `energySkillBonus`, `intuitionSkillBonus` to player skills |
| `Technology.js` | Wraps research data; delegates start/cancel/progress to ResearchSystem |

---

## Serialization

`ResearchSystem` does not have its own serialize/deserialize. Research state (active research, completed research, research points) is managed by `Nation` and `Technology` entities.
