# HiveMindAI Entity

Represents an advanced autonomous AI that fully runs a Hive Mind alliance. No real user nation holds leadership — every human member is a `Servant` with `basic` permissions only. The AI handles treaties, war, diplomacy, economy, membership applications, skill spending, settings, and role assignment autonomously.

## Overview

- **Class:** `HiveMindAI`
- **Globally available as:** `window.HiveMindAI`
- **Constructor:** `new HiveMindAI(alliance, aiName?, personality?)`
- **Government type:** `hiveMind` (special type)
- **Member role:** All human members are `Servant` (`basic` permissions only)
- **Exported catalog:** `window.HiveMindNameParts`, `window.generateRandomAIName()`, `window.generateRandomPersonality()`, `window.normalizeWeights()`

## Name Generation: 3 Sets of 100 Parts

Each AI name is generated by combining one part from each of three sets:

| Set | Count | Example Parts |
|-----|-------|---------------|
| Prefixes | 100 | `NEXUS`, `OMNI`, `VOID`, `CORE`, `QUANTUM` |
| Middles | 100 | `PRIME`, `ALPHA`, `OMEGA`, `SIGMA`, `ULTIMATE` |
| Suffixes | 100 | `MIND`, `CORE`, `SYSTEM`, `SINGULARITY`, `INFINITY` |

**Total combinations: 1,000,000**

Format: `PREFIX-MIDDLE-SUFFIX` (e.g., `NEXUS-PRIME-MIND`, `VOID-ALPHA-CORE`, `QUANTUM-SINGULARITY-OMNI`)

### `generateRandomAIName()`

Returns a randomly combined name from all three sets.

## Personality Profile

The personality starts randomized at creation and **evolves/learns** over time based on decision outcomes. A military-driven AI can become diplomacy-based, and vice versa.

### Personality Structure

| Field | Type | Description |
|-------|------|-------------|
| `weights.econ` | number (0-1) | Economic focus weight |
| `weights.mil` | number (0-1) | Military focus weight |
| `weights.diplo` | number (0-1) | Diplomatic focus weight |
| `risk` | number (0-1) | Aggression level |
| `learningRate` | number (0-0.1) | How fast personality adapts |
| `traits.expansionist` | number (0-1) | Recruitment drive |
| `traits.militaristic` | number (0-1) | Military preference |
| `traits.diplomatic` | number (0-1) | Diplomatic preference |
| `traits.economic` | number (0-1) | Economic preference |
| `traits.isolationist` | number (0-1) | Reluctance to recruit outsiders |
| `decisionCount` | number | Total decisions made |
| `successfulDecisions` | number | Successful decisions |
| `dominantStyle` | string | `'econ'`, `'mil'`, or `'diplo'` |
| `lastEvolution` | number | Last personality change timestamp |

Weights always sum to 1.0. `normalizeWeights()` is called after every mutation.

## Main Tick

### `async tick()`

Called once per day by `AllianceSystem.processGovernmentDaily()` for each hiveMind alliance. Evaluates and acts on every aspect of running the alliance:

| Subsystem | Chance/Day | Description |
|-----------|------------|-------------|
| Treaties | 35% | Propose or accept treaties with other alliances |
| War | 25% | Declare war on outside nations or hold defensive |
| Membership review | 15% | Kick inactive/underperforming members |
| Treasury | 20% | Withdraw surplus or deposit funds |
| Settings | 10% | Toggle open recruitment or update description |
| Skills | 30% | Spend alliance skill points autonomously |
| Applications | 25% | Accept/reject pending member applications |
| Invitations | 20% | Send recruitment invitations |
| Role assignment | 20% | Ensure all members are `Servant` |

Returns `{ actions, personality, favoredStat }`.

## Personality Evolution

### `evolvePersonality(actionCategory, success)`

Called after every executed decision. Adjusts personality based on outcome:

- **Successful action:** Nudges weights toward that category (`+learningRate`)
- **Failed action:** Nudges weights away from that category (`-learningRate`)
- **Military success:** Increases `risk` (aggression)
- **Military failure:** Decreases `risk`
- **Traits:** `expansionist`, `militaristic`, `diplomatic`, `economic` grow in their category; `isolationist` shrinks on success, grows on failure
- **Random drift:** Small ±0.01 weight drift each cycle simulates natural personality change
- **Weights re-normalized** to sum to 1.0 after every change

## Treaty Evaluation

### `_evaluateTreaties(alliance, members)`

Decides whether to propose a treaty to another alliance or accept an incoming proposal:

- **Propose** (45%): Picks random target alliance, selects treaty type based on personality weights
  - High diplomatic weight → `peace` or `intelligence`
  - High military weight → `mutualDefense` or `mutualAggression`
  - Balanced → random from all types
- **Accept** (35%): Scans pending proposals targeting this alliance via `DiplomacySystem.treatyProposals`
- **No action** (20%)

Treaty types: `peace`, `protectorate`, `mutualDefense`, `mutualAggression`, `intelligence`

### `respondToTreatyProposal(proposal)`

Verifies proposal targets this alliance, then accepts/declines based on diplomatic weight + randomness. Calls `evolvePersonality('diplo', accepted)`.

### `executeTreatyProposal(action)`

Executes a treaty decision:
- **Acceptance:** Validates proposal exists, targets this alliance, is pending, and not expired; calls `DiplomacySystem.acceptTreaty()`
- **Proposal:** Calls `DiplomacySystem.proposeAllianceTreaty()` with proposer/target alliance IDs and treaty type

## War Evaluation

### `_evaluateWar(alliance, members)`

Decides whether to go on the offensive or stay defensive:

- Aggressive roll based on `risk`, `favoredStat`, and military weight
- Only proceeds if an outside target nation exists
- War type: `alliance`, casus belli: `general_dispute`

### `executeWarDeclaration(action)`

Picks a random alliance member as attacker and a random outside nation as defender, then calls `WarSystem.declareWar()`.

## Membership Review

### `_evaluateMembership(alliance, members)`

20% daily chance to review membership. Prefers kicking inactive members (14+ days without activity), otherwise picks randomly. Only proceeds if more than 1 member exists.

### `executeMembershipKick(action)`

Removes target from alliance, sets their `allianceId = null`, logs the kick in `alliance.memberHistory`.

## Treasury

### `_evaluateTreasury(alliance, members)`

- Treasury > $50M and roll < 0.5 → withdraw 10%, distribute equally to members
- Treasury < $10M and roll < 0.6 → deposit $5M
- Otherwise: hold

### `executeTreasuryAction(action)`

Executes withdraw (distributes to all members) or deposit (adds to treasury).

## Settings

### `_evaluateSettings(alliance)`

- Roll < 0.3 → toggle open recruitment
- Roll < 0.6 → update description to `Managed by <AI name>`
- Otherwise: no action

### `executeSettingsAction(action)`

Sets `alliance.open` or `alliance.description` accordingly.

## Skills

### `_evaluateSkills(alliance, members)`

Spends alliance skill points autonomously:

1. Scores each upgradeable skill based on personality alignment:
   - Combat/marksmanship/offensive/defensive → military weight
   - Roster/member → expansionist trait
   - Customization/economy/upkeep/tech → economic weight
   - Diplomacy/treaty/unity → diplomatic weight
2. Bonus (+3) for personality's preferred skill style
3. Buys as many levels as affordable

### `executeSkillsAction(action)`

Calls `alliance.upgradeSkill(skillKey, levels)`. Evolves personality based on skill category.

## Applications (Fully Personality-Driven)

### `evaluateApplication(applicant, context)`

Core evaluation that scores each applicant from 0 to 1:

| Factor | Effect |
|--------|--------|
| **Isolationist > 0.6** | -0.25 × trait |
| **Isolationist < 0.3** | +0.15 |
| **Expansionist > 0.6** | +0.2 × trait |
| **At war** | -0.1 to -0.3 (militaristic AI less affected) |
| **Fought against previous alliance** | -0.2 to -0.35 (diplomatic AI forgives: +0.15) |
| **Previous alliance (no fight)** | +0.1 (if expansionist > 0.6) |
| **Wealthy applicant ($10M+)** | +0.15 (if econ weight > 0.4) |
| **Poor applicant (<$1M)** | -0.1 (if econ weight > 0.4) |
| **Strong military (>5000)** | +0.15 (if mil weight > 0.4) |
| **Weak military (<1000)** | -0.1 (if mil weight > 0.6) |
| **Diplomatic weight > 0.5** | +0.1 |
| **Randomness** | ±(risk × 0.1) |

Accept if score ≥ 0.5.

### `_evaluateApplications(alliance, context)`

Processes all pending applications. Context includes `atWar` and `wars` for fought-against detection. Returns array of `{ action: 'accept'\|'reject', nationId, ... }` actions.

### `executeApplicationDecision(action, alliance, server)`

Accepts (adds as `servant`, sets `allianceId`) or rejects (removes from applications) based on action type. Logs to `alliance.log`.

## Role Assignment

### `_evaluateRoleAssignment(alliance, members)`

For hiveMind government only: ensures ALL human members are assigned the `servant` role. Any member not already a servant gets reassigned.

### `executeRoleAssignment(action)`

Assigns the specified role to the nation via `alliance.assignRole()` or direct member assignment for plain objects.

### Persistence

AI state (`name`, `personality`, `memory`, `decisionHistory`, `isActive`, `createdAt`) is stored in `alliance.ai` and saved with `snapshot()` to `world.json`. Automatically restored on server restart — AI persists exactly like real player nations.

### Daily Processing

During world day advancement, each hiveMind alliance's AI is deserialized from saved state, runs `tick()`, executes actions, and serializes back.

## Execution

All execution methods are wrapped in try/catch so a failed action never crashes the daily tick:

| Method | Async | Actions Handled |
|--------|-------|-----------------|
| `executeTreatyProposal()` | Yes | Propose/accept treaties |
| `executeWarDeclaration()` | Yes | Declare war |
| `executeMembershipKick()` | No | Kick member |
| `executeTreasuryAction()` | No | Withdraw/deposit treasury |
| `executeSettingsAction()` | No | Toggle open/update description |
| `executeSkillsAction()` | Yes | Upgrade alliance skills |
| `executeInvitationsAction()` | No | Flag invitation intent |
| `executeRoleAssignment()` | No | Assign servant role |

## Serialization

### `serialize()`

Returns plain object: `{ allianceId, name, personality, memory, decisionHistory, isActive, createdAt }`

### `static deserialize(data, alliance)`

Restores AI from saved data. Merges saved memory with default keys so new fields aren't lost on version upgrades.

## Key Behavioral Rules

1. **No human leadership:** All members are `Servant` with `basic` permissions. Only the AI can make decisions.
2. **AI controls applications:** `allianceReview` is blocked for hiveMind — only the AI accepts/rejects applicants.
3. **Personality evolves:** Military AI can become diplomatic, diplomatic AI can become economic, etc.
4. **Persistent:** AI state survives server restarts via `world.json`.
5. **Favored stat rotates:** Each daily tick rotates between econ/mil/diplo so no single stat is always favored.
6. **Safe execution:** All actions wrapped in try/catch; failures never crash the tick.
